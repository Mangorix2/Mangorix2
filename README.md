* **KI & Daten:** Ich habe **SmaLLM** gebaut – eine eigene Implementierung eines Large Language Models in Python ohne dicke Bibliotheken. Ausserdem mache ich gerne Datenanalysen mit Pandas und Matplotlib.
* **Full-Stack:** In der Schule hab ich vieles verschiedene sachen gelernt, unteranderem React, JavaScript, Python, Java, SQL/NoSQL und Docker.
* **Projekte:** Ich versuche immer, theoretische Konzepte (wie neuronale Netzwerke) direkt in funktionierenden Code umzusetzen.
